# Technical reference

This directory contains curated background material. User and contributor
instructions are indexed in the [project README](../README.md#documentation-index).

- [Memory ownership and measurement](memory-ownership.md): retained storage,
  request lifetimes and the limits of host/device measurements.
- [C++ include reference](cpp_common_includes_cheatsheet.md): common standard
  headers and their APIs.
- [C++ and chip-inspection notes](mustKnow.md): value/reference deduction and
  the linked browser-based chip-inspection tool.

Raw investigations, board-specific scratch notes, proposals and session records
are local working material rather than maintained technical references.
